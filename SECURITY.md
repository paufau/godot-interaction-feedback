# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you have a security concern, you can always share it via:

1. [Raising a publicly visible issue](https://github.com/paufau/godot-interaction-feedback/issues/new/choose)
2. Contacting us personally paufau.games@gmail.com
